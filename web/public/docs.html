GETTING STARTED • 01

15-Minute Quickstart

Aven is the non-procedural programming language that replaces fragile imperative scripts with unbreakable mathematical invariants, compile-time physical unit tensors, and cryptographic audit trails.

1. Installation

Choose your platform installer or build from standard library Rust source with zero external dependencies:

# Linux, macOS & BSD (POSIX shell):
curl -proto '=https' --tlsv1.2 -sSf https://avenc.dev/install.sh | sh

# Windows (PowerShell):
iwr -useb https://avenc.dev/install.ps1 | iex

# Or compile locally from pure-std Rust source (zero crates):
cargo install --git https://github.com/Thrainkrilleve/aven.git

2. Verifying Installation

Verify that the compiler is on your path:

avenc --help
💡 Pure Standard Library Guarantee

avenc compiles with zero external crate dependencies. All lexing, AST lowering, symbolic differentiation, interval arithmetic, SMT transpilation, ANSI C emission, WebAssembly Core 1.0 emission, and package management run on 100% Rust std.

CONCEPTS • 02

The Relational Mindset

In procedural programming languages (Python, C, Rust), functions are one-way arrows. Direction of calculation is frozen at authoring time: 

# Procedural thinking: You must implement a separate function for every unknown!
def calc_force(mass, acceleration):
    return mass * acceleration

def calc_acceleration(force, mass):
    return force / mass

def calc_mass(force, acceleration):
    return force / acceleration

If you have a coupled system with 10 variables, procedural code requires authoring and maintaining dozens of distinct functions.

In Aven, you state the physical law once. The compiler deduces which unknowns need to be calculated based on what you observe: 

// The invariant law is declared once
relation Dynamics {
    force = mass * acceleration
}

Aven dynamically calculates force, mass, or acceleration using exact symbolic Jacobians and Newton-Raphson relaxation.

TUTORIAL • 03

Your First Relation

Let's model a harmonic physical pendulum where the oscillation period $T$ relates to rod length $L$ and gravitational acceleration $g$:

$$T = 2\pi\sqrt{\frac{L}{g}}$$

Create a file named pendulum.aven:

// pendulum.aven
relation Pendulum {
    period = 2.0 * 3.1415926535 * sqrt(length / gravity)
}

// Scenario 1: Forward calculation (earth gravity)
solve Pendulum with {
    length = 0.994
    gravity = 9.80665
}

// Scenario 2: Inverted calculation (find length for a 2.0-second period)
solve Pendulum with {
    period = 2.0
    gravity = 9.80665
}

Run the model using the native toolchain:

avenc run pendulum.aven

In Scenario 2, Aven symbolically inverts the square root and calculates length = 0.9936 automatically without any procedural reorganization.

RECIPE • 05

Omnidirectional Solving

When equations are non-linear or multi-variable coupled, Aven constructs exact analytical symbolic Jacobians and applies multidimensional Newton-Raphson relaxation until the Euclidean residual norm satisfies:

||F(x)||_2 ≤ 10^-6 

relation RocketPropulsion {
    thrust = mass_flow * exhaust_velocity + (exit_pressure - ambient_pressure) * exit_area
    specific_impulse = thrust / (mass_flow * 9.80665)
}

// Solve for required mass flow to hit a target specific impulse and thrust
solve RocketPropulsion with {
    thrust = 220000.0
    specific_impulse = 310.0
    exit_pressure = 101325.0
    ambient_pressure = 101325.0
    exit_area = 0.85
}
avenc run rocket.aven
RECIPE • 06

Units & Physical Dimensions

Aven enforces compile-time dimensional checking across the 7 SI base quantities:

[ Mass (kg), Length (m), Time (s), Current (A), Temperature (K), Substance (mol), Luminous Intensity (cd) ] 

signal speed : km/h
signal time_elapsed : s
signal distance_travelled : m
signal mass : kg

relation Kinematics {
    distance_travelled = speed * time_elapsed
    acceleration = speed / time_elapsed
    force = mass * acceleration
}

solve Kinematics with {
    speed = 100 km/h
    time_elapsed = 10 s
    mass = 1500 kg
}
⚠️ Compile-Time Dimensional Defense

If you mistakenly write distance_travelled = speed + time_elapsed, avenc aborts compilation with a dimensional mismatch error ([L T^-1] vs [T]) before any runtime execution begins.

RECIPE • 07

Mixed-Integer Optimization

Physical architecture decisions often require discrete integer quantities (e.g. integer servers, hard drives, gear teeth). Aven includes a native branch-and-bound mixed-integer solver: 

relation CloudCapacity {
    int worker_nodes
    total_cores = worker_nodes * cores_per_node
    total_ram_gb = worker_nodes * ram_per_node_gb
    monthly_budget = worker_nodes * node_cost_monthly

    // Invariant capacity constraints
    total_cores >= target_cores
    total_ram_gb >= target_ram_gb
}

solve CloudCapacity with {
    cores_per_node = 16.0
    ram_per_node_gb = 64.0
    node_cost_monthly = 145.0
    target_cores = 100.0
    target_ram_gb = 350.0
    minimize(worker_nodes)
}
RECIPE • 08

C99 Code Generation

For safety-critical embedded targets (automotive ECUs, microcontrollers, bare-metal robotics), Aven compiles direction-pinned forward blocks directly into freestanding ANSI C99 with zero dynamic allocations: 

// governor.aven
forward ThrottleGovernor(target_rpm, current_rpm, kp, base_throttle) -> (throttle_output) {
    error = target_rpm - current_rpm
    adjustment = error * kp
    throttle_output = base_throttle + adjustment
}

Emit freestanding C:

avenc emit-c governor.aven -o governor.c

The generated code compiles with gcc -std=c99 -Wall -Werror -pedantic and requires no external libraries beyond standard freestanding headers (stdint.h, stdbool.h, math.h).

RECIPE • 09

WebAssembly Core 1.0 Emission

Aven compiles relations to standard WebAssembly Core 1.0 binaries using standard LEB128 encoding: 

# Emit standard WebAssembly binary (.wasm)
avenc emit-wasm governor.aven -o governor.wasm

# Inspect human-readable WebAssembly Text (.wat)
avenc emit-wasm governor.aven --wat

Run natively in browser or Node.js:

const fs = require('fs');
const wasmBytes = fs.readFileSync('governor.wasm');

WebAssembly.instantiate(wasmBytes).then(({ instance }) => {
    // Direct exported function: ThrottleGovernor(base, current, kp, target)
    const throttle = instance.exports.ThrottleGovernor(40.0, 2800.0, 0.25, 3000.0);
    console.log("Settled Throttle %:", throttle); // 90.0
});
RECIPE • 10

Real-Time Telemetry & Adapters

Aven connects to live sensors, message brokers, and telemetry streams via subprocesses, IPC sockets, or shared memory rings: 

// Ingest from external Python simulator:
using external("python", "sensor_stream.py") {
    current_altitude_m
    outside_temp_c
}

// Ingest from persistent local TCP daemon:
using ipc("127.0.0.1:9090") {
    turbine_vibration_g
}

// Ingest from low-latency POSIX shared memory ring buffer:
using shm("/dev/shm/telemetry_ring") {
    shaft_torque_nm
}

Every external observation is hashed with SHA-256 and committed into the immutable append-only fact ledger (.aven_ledger.jsonl).

AUTHORITATIVE • STANDARDS.md

Aven Engineering & Mathematical Standards

This section defines the official engineering, numerical, cryptographic, and architectural standards for the Aven compiler (avenc), runtime targets, and ecosystem.

1. Architectural Separation ("Rust Compiles, C Runs")

  • Compiler Layer (avenc): 100% pure standard library Rust (std). Zero third-party crate dependencies in Cargo.toml.
  • Execution Runtime Layer (aeric/): Standard freestanding ANSI C99 (-std=c99 -pedantic -Wall -Werror). Zero dynamic heap allocations (malloc, free) during steady-state solving.

2. Mathematical Rigor & Numerical Stability

  • Precision: IEEE-754 double-precision 64-bit binary floating-point (f64).
  • Domain Guards: Active bounds checking against division by zero ($|d| < 10^{-15}$), non-positive logarithms ($x \le 0$), and negative square roots ($x < 0$).
  • Exact Jacobians: Coupled multidimensional relaxation must evaluate derivatives via exact symbolic differentiation; finite-difference approximations are strictly prohibited in core relaxation kernels.
  • Convergence Metric: System settled if Euclidean residual norm satisfies $\|F(\mathbf{x})\|_2 = \sqrt{\sum_{i=1}^n f_i(\mathbf{x})^2} \le 10^{-6}$. Deterministic iteration ceiling: $N_{\max} = 100$.

3. 7-Dimensional SI Base Tensor & Homogeneity

Aven enforces compile-time dimensional checking across the 7 fundamental SI base quantities $[M, L, T, I, \Theta, N, J]$:

SymbolQuantitySI Base UnitAven Identifier
MMasskilogramkg
LLengthmeterm
TTimeseconds
IElectric CurrentampereA
ΘThermodynamic TemperaturekelvinK
NAmount of Substancemolemol
JLuminous Intensitycandelacd

Homogeneity rules dictate that in any equation $LHS = RHS$, $[d_{LHS}] == [d_{RHS}]$. Dimensional violations abort compilation prior to code generation.

4. Cryptographic Provenance & Fact Ledgers

  • Hash Standard: All digests, model signatures, and seals use standard SHA-256 (NIST FIPS 180-4).
  • Append-Only Merkle Chain: Each fact recorded in .aven_ledger.jsonl chains to previous state via:
    H_k = SHA256(H_{k-1} || Payload_k)
  • Tamper Detection: Segmented telemetry directories verify cryptographic continuity across every segment. Any altered entry immediately fails verification.

5. Temporal Streams & Signal Calculus

  • Bounded Buffers: stream<T, N> allocations are bounded circular FIFO rings with compile-time $O(N)$ memory ceiling.
  • Staleness & TTL: Ingested telemetry enforces Time-To-Live. Stale observations without valid fallback exit with Code 3.
  • Committed Boundaries: Irreversible physical effects (e.g. valve opening, motor fire) cannot be rewound by time-travel debuggers without explicit --force.

6. Target Code Emission Standards

  • ANSI C99: Direction-pinned forward blocks compile to freestanding C with topologically sorted execution order and zero dynamic memory allocations.
  • WebAssembly Core 1.0: Binary output conforms to W3C recommendation with dual-ABI support (direct function exports & memory-mapped aven_solve(in_ptr, out_ptr)).

7. Deterministic CLI Exit Codes

Exit CodeIdentifierSemantic Meaning
0SUCCESSModel converged, all equations and constraints satisfied.
1SOLVE_ERRORSingular Jacobian, division by zero, or compiler syntax error.
2CONSTRAINT_VIOLATIONEquations converged, but user-defined inequalities failed.
3STALE_INPUTTelemetry fact exceeded its Time-To-Live (TTL) without fallback.

8. Testing & Quality Assurance Mandates

  • Golden Tests: Verify known physical ground truths (atmosphere, orbital mechanics, Markowitz frontier).
  • Randomized Stress Tests: OS-entropy-seeded property tests verifying numerical stability.
  • Zero Warning Policy: Entire repository builds with zero warnings under cargo test --release.

Package Specification (.avenpkg)

Aven packages are distributed as standalone, cryptographically sealed .avenpkg binary archives: 

// Aven.toml manifest
[package]
name = "std_aerodynamics"
version = "0.2.1"
entry = "lib.aven"
authors = ["Aven Aeronautics WG <admin@avenc.dev>"]
license = "MIT"
description = "US Standard Atmosphere 1976 and Mach compressibility relations"

[dependencies]
std_thermodynamics = "0.1.4"
