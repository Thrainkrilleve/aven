Getting Started with Aven

Aven is the non-procedural programming language that replaces fragile imperative scripts with unbreakable mathematical invariants and cryptographic audit trails.

1. Installation

# Linux, macOS & BSD:
curl -proto '=https' --tlsv1.2 -sSf https://avenc.dev/install.sh | sh

# Windows (PowerShell):
iwr -useb https://avenc.dev/install.ps1 | iex

# Or build from pure-standard-library Rust source:
cargo install --git https://github.com/Thrainkrilleve/aven.git

2. The Relational Mindset

In procedural code, functions are one-way arrows:

# Procedural thinking (one function per unknown):
def calc_force(mass, acceleration): return mass * acceleration
def calc_mass(force, acceleration):  return force / acceleration

In Aven, you declare physical invariants once:

relation Dynamics {
    force = mass * acceleration
}

Aven solves for force, mass, or acceleration dynamically using exact symbolic Jacobians and Newton-Raphson relaxation.

3. Omnidirectional Solving Example

// dynamics.aven
relation Dynamics {
    force = mass * acceleration
}

// Forward: Solve for force given mass and acceleration
solve Dynamics with {
    mass = 1200.0
    acceleration = 3.5
}

// Backward: Solve for mass given target acceleration and available force
solve Dynamics with {
    force = 4200.0
    acceleration = 5.0
}

Run the model:

avenc run dynamics.aven

4. Physical Units & 7-D Dimensional Tensors

Aven validates physical dimensions at compile-time across SI base dimensions: Mass $[M]$, Length $[L]$, Time $[T]$, Current $[I]$, Temperature $[\Theta]$, Substance $[N]$, and Luminous Intensity $[J]$.

signal speed : km/h
signal time_elapsed : s
signal distance_travelled : m

relation Kinematics {
    distance_travelled = speed * time_elapsed
    acceleration = speed / time_elapsed
    force = mass * acceleration
}

solve Kinematics with {
    speed = 100 km/h
    time_elapsed = 10 s
    mass = 1500 kg
}

If you accidentally add seconds to speed (speed + 10 s), Aven immediately rejects compilation before any code executes.

5. Mixed-Integer Optimization & Constraints

Physical systems require discrete integer decisions (e.g. integer servers, hard drives, gear teeth). Aven natively incorporates branch-and-bound mixed-integer simplex solving:

relation ServerProvisioning {
    int nodes
    total_cores = nodes * cores_per_node
    total_ram_gb = nodes * ram_per_node_gb
    total_cost_monthly = nodes * node_monthly_cost
    
    // Invariant inequalities:
    total_cores >= required_cores
    total_ram_gb >= required_ram_gb
}

solve ServerProvisioning with {
    cores_per_node = 16.0
    ram_per_node_gb = 64.0
    node_monthly_cost = 145.0
    required_cores = 100.0
    required_ram_gb = 350.0
    minimize(nodes)
}

6. Compiling to Freestanding C99

For embedded microcontrollers or automotive ECUs, forward blocks compile to branchless, solver-free ANSI C99:

avenc emit-c governor.aven -o governor.c

7. Compiling to WebAssembly

# Emit standard binary WASM
avenc emit-wasm governor.aven -o governor.wasm

# Inspect WebAssembly Text format
avenc emit-wasm governor.aven --wat

9. Package Registry & Commands

# Initialize a new package with Aven.toml
avenc pkg init my_physics_lib

# Pack into a cryptographic .avenpkg archive sealed with SHA-256
avenc pkg pack

# Install into local registry
avenc pkg install my_physics_lib-0.1.0.avenpkg

# List installed packages
avenc pkg list
